# QMS-Copilot — ISO 9001 Compliance & Audit Agent

QMS-Copilot is an intelligent, evidence-based Quality Management System (QMS) modernization and ISO 9001 audit-readiness assistant built with Python, Streamlit, FAISS, and Google Gemini.

## Quick Start
1. Clone the repository.
2. Ensure your extracted FAISS vector store is placed at `data/vectorstore/iso_faiss_index/`.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
